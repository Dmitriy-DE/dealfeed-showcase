# Privacy model

- Anonymous authentication is used to avoid mandatory account creation.
- Row Level Security limits user-owned records.
- Analytics consent and advertising consent are independent.
- Server-side event storage avoids unnecessary personal fields.
- Data deletion removes bookmarks/profile state and de-identifies retained aggregate events.
- Provider secrets live only in server-side/edge environments.
- Redirect targets are checked against an allow-list.

The public showcase contains no real analytics keys, advertising IDs or affiliate credentials.
